📖 Hướng dẫn thao tác

  1. Tải File TKB: Bấm vào nút "Tải File TKB" để upload file Excel/CSV danh sách lớp mở của trường.
  2. Lọc & Tìm kiếm: Sử dụng ô tìm kiếm và các bộ lọc (Khoa, Giảng viên, Buổi) để tìm lớp học mong muốn.
  3. Thêm môn: Click vào một lớp trong bảng "Lớp mở" (bên trái) để thêm vào TKB (bên phải). Cảnh báo nếu lớp bị trùng giờ. Click lại vào môn đã đăng ký để xóa.
  4. Xuất TKB: Bạn có thể In PDF, Xuất Excel, Lưu file JSON (để backup) hoặc Copy trực tiếp hình ảnh TKB.

⚡ TEX-TOOL DKHP Script Generator

Công cụ hỗ trợ tạo đoạn mã JavaScript cá nhân hóa để tự động chọn lớp trên trang Đăng ký học phần.

  • Lên cấu hình thời khóa biểu bạn mong muốn.
  • Nhấn nút "📋 Copy Script" ở panel TEX-TOOL DKHP Generator.
  • Đăng nhập dkhp.uit.edu.vn, mở DevTools (F12) tab Console.
  • Paste và Enter để script tự động thêm môn!

⚡ TEX-TOOL | Hướng dẫn DKHP Script

Các bước thực hiện

  1. Xếp xong Thời khóa biểu với các lớp bạn cần đăng ký trên trang TEX-TOOL.
  2. Nhấn nút "📋 Copy Script" trong panel "DKHP Script Generator". Mã sẽ được lưu vào Clipboard.
  3. Truy cập và đăng nhập vào trang dkhp.uit.edu.vn.
  4. Nhấn phím F12 (hoặc Ctrl+Shift+I) để mở Developer Tools, chuyển sang tab Console.
  5. Dán (Paste) đoạn script vừa copy vào Console và nhấn Enter.
  6. Đợi script chạy xong. Nó sẽ tự động tìm các mã lớp trong bảng và click chọn giúp bạn.
